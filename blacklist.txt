# 黑名单规则（每行一条，本文件由用户维护；# 开头为注释）
# 处理脚本 src/process.py 在 Actions 生成 cq.m3u 之后运行，按这些规则过滤。
#
# 规则格式：
#   name:关键字       显示名含“关键字”即屏蔽（大小写不敏感）
#   tvgid:xxx         tvg-id 含 xxx 即屏蔽
#   host:1.2.3.4:port 来自该网关的线路即屏蔽（剔除坏源）
#   group:关键字      分组含“关键字”即屏蔽
#   纯文本(无前缀)    等价于 name:纯文本
#
# 当前列表（重庆组播 重庆联通 / 6 个网关）暂无需屏蔽项；按需追加即可。
# 临时测试也可不设本文件，直接给 workflow/本地加环境变量 BLACKLIST=关键字1,关键字2。

# 示例（取消注释即生效）：
# name:测试
# name:未命名
# name:unknown
# host:27.8.49.135:4022
